# Plaimanas Practical Test

This project is a practical assignment provided by Plaimanas.com.  
It was developed using **HTML, CSS, and JavaScript**, focusing on clean structure, responsive layout, and smooth user interactions.

## Demo

https://plaimanas-practical-test.vercel.app/

## Features

- Responsive layout for desktop and mobile
- Clean and semantic HTML structure
- Modern CSS styling and transitions
- Interactive components using JavaScript
- Smooth animations for better user experience

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Library

- GSAP - for auto scrolling content

## Getting Started

1. Clone the repository

2. Open the project folder

3. Run the project

   Simply open index.html in your browser.
